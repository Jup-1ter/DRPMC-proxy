# Предназначение
## Удаление команд
### /velocity
Позволяет узнать тип и версию прокси.
### /server
Позволяет подключиться к любому серверу в сети. Критическая угроза безопасности.
## Перенаправление игроков
Если IP игрока совпадает с IP последней авторизации, то игрок сразу перенаправляется на игровой сервер (или в лобби).
Если нет, то игрок попадает на сервер авторизации.
# Технические особенности
## Конфигурация
Конфигурация отсутствует. Ссылка на БД, драйвер и другие необходимые параметры указываются прямо в коде.
## Зависимости
Все зависимости включаются в файл плагина при сборке.
